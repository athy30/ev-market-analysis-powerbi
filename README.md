# EV Market Analysis Dashboard

An interactive Power BI dashboard analyzing electric vehicle (EV) data to identify trends across manufacturers, vehicle models, EV types, model years, and electric driving range.

## Project Overview

This project analyzes a dataset containing **299,705 electric vehicle records** and uses Power BI to transform the raw data into an interactive business intelligence dashboard.

The project focuses on understanding the EV market through manufacturer performance, popular vehicle models, vehicle type distribution, model-year trends, and electric range.

## Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Data Modeling**
- **Data Cleaning & Transformation**
- **Data Visualization**

## Dataset

The dataset contains information related to electric vehicles, including:

- VIN
- Country
- City
- State
- Postal Code
- Model Year
- Make
- Model
- Electric Vehicle Type
- Clean Alternative Fuel Vehicle (CAFV) eligibility
- Electric Range

**Total records:** 299,705

## Data Preparation

The dataset was cleaned and transformed using **Power Query** before building the dashboard.

The preparation process included:

- Reviewing data quality
- Handling incomplete records
- Checking column data types
- Cleaning and transforming fields
- Preparing the data for analysis and visualization

## Dashboard Analysis

The dashboard provides analysis of:

- Total number of EVs
- BEV vs PHEV distribution
- Average electric range
- EV records with zero electric range
- EV trends by model year
- Manufacturer-level analysis
- Popular EV models
- Geographic distribution
- Interactive filtering and exploration

## Key Analysis

### EV Type Distribution

The dataset contains two major electric vehicle categories:

- **Battery Electric Vehicles (BEV):** 241,724
- **Plug-in Hybrid Electric Vehicles (PHEV):** 57,981

BEVs represent approximately **80.7%** of the dataset, while PHEVs represent approximately **19.3%**.

### Top Manufacturers

The leading manufacturers by number of vehicles in the dataset include:

1. Tesla — 122,981
2. Chevrolet — 20,236
3. Ford — 16,118
4. Nissan — 16,053
5. Kia — 14,776

### Top EV Models

The leading models include:

1. Tesla Model Y — 66,545
2. Tesla Model 3 — 39,391
3. Nissan Leaf — 13,453
4. Tesla Model S — 7,873
5. Chevrolet Bolt EV — 7,642

## DAX & Power BI

DAX measures were created to support key dashboard metrics, including:

- Total EV count
- BEV/PHEV distribution
- Average electric range
- Zero-range EV records

Power BI visualizations and interactive filters were then used to allow users to explore the dataset from different perspectives.

## Project Outcome

The final dashboard converts a large raw EV dataset into an interactive analytical report that can be used to explore market composition, manufacturer performance, model popularity, and EV characteristics.

This project demonstrates practical skills in **data cleaning, Power Query, DAX, data modeling, visualization, and exploratory analysis using Power BI**.
